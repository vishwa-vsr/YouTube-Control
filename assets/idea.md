# Future Feature Ideas

## Twitch-Style Timestamped Comments
- **Source:** Reddit user `CowNo3` on `r/browsers`
- **Idea:** Show comments that contain timecodes (like `01:23`) as a live scrolling overlay or chat feed while the video plays, similar to Twitch live chat / VOD chat replay.
- **Details:** 
  - Parse comment timestamp links from the comments section.
  - Sync them with the video player's current playback time (`currentTime`).
  - Display comments on screen at the exact second they are mentioned in the video.

## Auto-Convert / Redirect Shorts to Regular Video Player
- **Source:** Reddit user `Sufficient_Risk_8127`
- **Idea:** Add an option to convert YouTube Shorts URLs (`/shorts/VIDEO_ID`) into standard video player URLs (`/watch?v=VIDEO_ID`).
- **Details:** 
  - Gives users full player controls (seeking, playback speed, standard comments) while eliminating the addictive vertical infinite scroll reel interface.

## YouTube Comment Screenshot Capture
- **Source:** Feature Suggestion
- **Idea:** Add a 1-click screenshot button on YouTube comment cards to save clean image snapshots of individual comments.
- **Details:** 
  - Renders comment text, author avatar, timestamp, and like count onto a high-quality PNG image for easy sharing.

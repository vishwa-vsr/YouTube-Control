# YouTube Control — Store Listing Description

> **Ready-to-copy store description for Chrome Web Store, Firefox Add-ons, and Edge Add-ons.**

---

### Option 1: Complete Version (Includes Latest Features)

```text
YouTube Control gives you 15+ tools to block distractions and customize every part of YouTube — from the home feed to the video player.

✦ BLOCK SHORTS & CLEAN YOUR FEED
• Block YouTube Shorts — remove Shorts feeds, Shorts shelves, and Shorts tabs completely
• Hide Home Feed — turn off video recommendations on the YouTube homepage
• Hide Category Bar — remove filter chips (Trending, Music, Gaming, etc.)
• Custom Grid Rows — choose 2, 3, 4, 5, or 6 thumbnails per row
• Clean Sidebar — hide Explore tabs, subscription lists, and "You" sections

✦ CUSTOMIZE YOUR WATCH EXPERIENCE
• Dock Comments to Sidebar — read comments right next to the video, no scrolling
• Sticky Video Player — keep the video pinned while you scroll through comments
• Speed Switcher — 1-click switcher between 3 custom playback speeds (saved across videos)
• Refresh Comments — reload new comments with 1 click without refreshing the page
• Comment Screenshot — capture full comment threads and copy to clipboard as images
• Hide Related Videos — remove suggested video sidebar
• Hide Comments & Live Chat — turn off comments and live chat entirely
• Hide Stats & Buttons — remove view counts, like counts, and subscribe buttons

✦ VISUAL TOOLS & POWER FEATURES
• Blur Thumbnails — soften thumbnails until hover to avoid clickbait
• Black & White Mode — apply grayscale to YouTube while keeping videos in full color
• Block Ambient Mode — disable glowing background effects (saves GPU power)
• Hide Scrollbars — remove visual scrollbars while keeping smooth mouse scrolling
• Video Screenshot — capture full-resolution video frames with one click
• Theater Max (Mini Fullscreen) — borderless window mode without hiding your browser tabs

✦ WHY YOUTUBE CONTROL?
Unlike single-purpose Shorts blockers, YouTube Control lets you customize exactly which distractions to remove. Toggle each feature on or off — no all-or-nothing.

✦ PRIVACY FIRST
YouTube Control runs 100% locally. Zero tracking. Zero data collection. Zero network requests. Your browsing stays private.

✦ OPEN SOURCE
Fully open source and community-driven. Inspect the code, report bugs, or contribute:
https://github.com/vishwa-vsr/YouTube-Control

✦ WORKS ON
Chrome • Firefox • Edge
```
